# 🚀 ResumeBuilder – AI Powered Resume Builder
ResumeBuilder is a full-stack web application that helps users create, manage, customize, and share professional resumes with ease. The platform provides multiple resume templates, PDF export, premium features, email sharing, authentication, and payment integration.

---

## ✨ Features

### 👤 User Features

* User Registration & Login
* JWT Authentication & Authorization
* Create Professional Resumes
* Edit Existing Resumes
* Preview Resume Before Download
* Multiple Resume Templates
* Download Resume as PDF
* Email Resume Directly
* Dashboard for Resume Management
* Premium Membership Features

### 💳 Premium Features

* Premium Resume Templates
* Advanced Resume Customization
* Payment History
* Razorpay Payment Integration
* Premium Access Control

### ☁️ Cloud Features

* Cloudinary Image Upload
* Secure Resume Storage
* MongoDB Database Integration

## ⚙️ Installation

### Clone Repository

bash
git clone https://github.com/vcetsachin/ResumeBuilder.git
cd ResumeBuilder


### Backend Setup

bash
cd ResumeBuilder
mvn spring-boot:run


### Frontend Setup

bash
cd resume-builder-frontend
npm install
npm run dev
